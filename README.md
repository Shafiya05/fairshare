# FairShare – Team Contribution Intelligence

A Streamlit dashboard that analyses **real GitHub repository activity** to give a fair, data-driven picture of every team member's contributions.

---

## Features

| Feature | Description |
|---------|-------------|
| 📊 Contributor Statistics | Commits, pull requests, issues and comments per person |
| 📅 Weekly Activity Timeline | Line chart and table of activity grouped by week |
| 🚨 Inactive Member Alerts | Flags contributors with no activity in the last 30 days |
| 🤖 AI Contributor Summaries | Two-sentence summaries generated by Gemini (optional) |
| 👤 Duplicate Identity Mapping | Merge multiple GitHub logins under one display name |
| 🔴 Live Auto-Refresh | Auto-refreshes GitHub data every 5 minutes when enabled |
| 📥 Downloadable Reports | CSV exports: contributor stats, weekly activity, inactive members, AI summaries, combined |

---

## Technology Stack

| Component | Technology |
|-----------|-----------|
| Dashboard | [Streamlit](https://streamlit.io) 1.67 |
| Data analysis | [Pandas](https://pandas.pydata.org) |
| GitHub data | [GitHub REST API v3](https://docs.github.com/en/rest) |
| AI summaries | [Google Gemini API](https://ai.google.dev) (via REST) |
| HTTP client | `requests` (stdlib-based) |
| Language | Python 3.10+ |

## Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/Shafiya05/fairshare.git
cd fairshare
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure API credentials

Create `.streamlit/secrets.toml` (this file is ignored by Git):

```toml
GITHUB_TOKEN   = "ghp_your_personal_access_token_here"
GEMINI_API_KEY = "AIza_your_gemini_api_key_here"
GEMINI_MODEL   = "gemini-2.0-flash"
```

**How to get credentials:**

- **GitHub Token:** https://github.com/settings/tokens → Generate new token (classic) → Select `public_repo` scope
- **Gemini API Key:** https://aistudio.google.com/apikey → Create API key

> ⚠️ **Never commit these files.** `.gitignore` already excludes them.

### 4. Run the application

```bash
streamlit run app.py
```

The dashboard opens at `http://localhost:8501`.

## How to Use

1. Paste any GitHub repository URL into the input box.
2. Click **Analyse Repository**.
3. View contributor statistics, charts, and alerts.
4. Enable **Live Mode** (sidebar) for automatic 5-minute refreshes.
5. Add identity mappings (sidebar) if a team member uses multiple accounts.
6. Expand **AI Contributor Summaries** to generate Gemini-powered summaries.
7. Download reports using the buttons in the **Downloadable Reports** section.

## Known Limitations

- **GitHub API rate limits:** Without a token, the API allows 60 requests/hour. With a token: 5,000/hour. Large repositories may hit this limit.
- **Data scope:** Fetches up to 500 items per activity type (5 pages × 100 items). Very large repositories show only the most recent activity.
- **Live refresh:** Uses Streamlit's `st.rerun()` with a 1-second sleep loop. This is acceptable for a dashboard but not suitable for high-performance applications.
- **AI summaries:** Require a valid Gemini API key and internet access. Summaries are cached for 1 hour.
- **Excel export:** Not implemented (requires `openpyxl`). CSV exports cover all data.
- **Identity mapping:** Stored in session state only — not persisted between browser sessions.

## Security Notes

- Credentials are stored only in `.streamlit/secrets.toml` and `.env` (both gitignored).
- Credentials are never printed, logged, or included in source code.
- The application uses `Bearer` token authentication for GitHub requests.
